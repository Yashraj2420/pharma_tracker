# Pharma Tracker

## Overview
Pharma Tracker is a web-based application developed to help manage pharmaceutical inventory, medicine records, and user access efficiently. The project focuses on improving inventory tracking and reducing manual work.

## Features
- User authentication and login
- Medicine inventory management
- Add, update, and delete medicine records
- Search and filter medicines
- Dashboard for inventory monitoring

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Security Features
- User authentication
- Role-based access control
- Input validation
- Secure database operations
- Password protection
